Run with a modern Python supporting int.bit_count():
  python independent_reference.py --output independent_checks.json

No third-party Python packages are required by the reference program.
The script performs 19 named independent CPU arithmetic/reference groups.
These are not the original solvefinite tests and do not execute GPU shaders,
endpoint protocols, repository captures, or persistence/fault-injection tests.
Case counts refer to each stated scope, not an architectural completion score.

Original Revision 15 reports a 796-test / 179-device-method DP/Wv2 capture.
That historical verification is preserved as source-reported evidence, not rerun.
VP/Wv3 remains FORMAL ONLY. Selected volume arithmetic is checked here;
this does not supply its runtime, device production or durable continuation.
LG is a new optional mathematical phase-window primitive, not a registered
runtime profile and not a modification of existing manifests or W schemas.

revision15-original.pdf is the exact uploaded authoritative baseline.
source_manifest.json hashes both supplied PDFs. The corpus itself is not
reproduced wholesale; the upgraded document gives precise page concordance.

companion bundle. Such an audit checks document construction, not the kernel's
