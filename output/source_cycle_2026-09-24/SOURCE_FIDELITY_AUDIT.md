## Observed static wiring

The source joins body, field and anchor in `kernel.py:45–46`; application resolves that record at `79–80`. The compiler's `Plan.situated`, lines 356–372, resolves the current placement, computes the nearest Klein lift, invokes the current field and passes the result into the current body. Source-level LUT context is bound here to actual resident record lookup and that record's situated field. It is not a computation over every record on each semantic call.

Each lane has its own complete substrate instance. Native `resident_v2.inc:223–267` reads one old image for all mutation targets, validates proposed records, performs action with the candidate table, then commits; any failure restores the whole preceding image and records the first failure. Typed family dispatch is at lines 119–126 and 160–182. All targets therefore use the old mutator/pinion during one mutation pass. A changed mutator body governs the following mutation pass, while newly published records govern the current action phase.

The current K and anchors are canonical chart points. Intrinsic radial disk distance is reflection invariant, so omitting the query orientation from that scalar distance is appropriate. These checks establish the declared discrete chart operations; they do not establish smooth metric or tangent covariance for the complete circulation.

## Runtime evidence is separate

This audit does not supply CPU/GPU comparison counts, performance measurements or intervention results. The campaign's [cycle intervention summary](cycle_intervention_summary.json) and [baseline summary](cycle_baseline_summary.json) link the actual retained program/checkpoint/receipt evidence. Those records must be read with their program, generator and executable hashes. A changed numerical result under a body/field/placement/history intervention demonstrates causal participation for that recorded experiment; it does not by itself prove that the numerical law is the unique interpretation of the source. Static wiring and observed intervention sensitivity are complementary findings.

## Explicit edition boundaries

- Selected-action role 99 is supplied for source indices 7–12, the six geometric operators. All 31 records exist, but other selected-call types are not silently adapted.
- The bank and supported body-family variants are finite. Mutating a handle selects a complete validated authored definition; it does not synthesize arbitrary new source expressions or grow the bank.
- An abstract source LUT argument is concretized through current resident lookup and situated record context. The scalar and vector projections, two-complex-channel wave, finite B history, finite phase history and 2x2 T/A matrix are declared choices. Some retained state words are snapshots/diagnostics rather than independent next-epoch inputs. Supplied jitter, neck and route controls are persistent inputs; no random/physical generator is claimed.
- The source catalogue, phase array, fourth-slot Y-up count and wavefront seed are checked/consumed. Unsupported changed source-slot declarations fail. This is a particular numerical edition, not an interpreter for every possible symbolic source edit.
- Optional BC5 texture encoding remains unsupported and fails on invocation. The optional threshold readout is not a Bayer texture layout. Neither is part of the completed core circulation claim.
- The runtime executes independent per-lane substrate instances. It does not establish a shared common LUT across a population, unbounded computation, physical new-law validity, general optimization, or full smooth metric covariance.
- No biochemical or other domain application is delivered by this cycle binding. Domain constraints need an explicit task mapping and their own objective evidence.

Within those stated boundaries, the final static inspection found no further concrete missing direct stage dependencies after tracing the eight source phases, current operator-slot dispatch, transaction timing and returned-state feedback.
